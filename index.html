Task Email Alert Configuration

Configure overdue task notifications for selected main phases, subphases and individual tasks.

● Notification control active

1. General Settings

Define when the notification process should run.

2. Email Configuration

Configure who should receive overdue-task notifications and define the email content. Dynamic tags can be used in the subject and body so each notification automatically includes the recipient name, notification date, number of overdue tasks, and a clickable list of the relevant tasks.

Enter one or more recipient email addresses separated by semicolons.
Also notify assigned users When enabled, each assigned user receives a list of their own overdue tasks with clickable task links. When disabled, only the configured Email To recipients receive the notification.
{{date}}{{user_name}}{{overdue_count}}
{{user_name}}{{task_list}}{{overdue_count}}{{date}}

3. Phase & Task Selection

Select the phases and individual tasks that should trigger overdue email alerts.

Select only the phases and tasks that should generate overdue email notifications. For example, you can enable notifications for all tasks in Main Phase 1 while leaving Main Phase 3 excluded.
